# SMARTIVE renewal draft

회사 관계자 협의용 한국어 웹사이트 초안입니다. `dist`를 정적 웹 서버로 제공하면 실행됩니다. 빌드나 외부 패키지가 필요하지 않습니다.

## 포함 화면

- 기업 소개, 분석 서비스와 서비스별 상세
- 공지 분류·검색·상세와 운영자 작성·수정·삭제·상단 고정
- 분석 의뢰 양식과 접수 완료
- 고객 의뢰 목록, 상태별 필터, 단계별 진행 표시
- 의뢰별 고객·운영자 대화
- 운영자 상태 변경과 예시 보고서 발급
- 예시 보고서 보기·HTML 내려받기·인쇄/PDF 저장
- PC·모바일 반응형 화면

## 데이터 범위

모든 업무 데이터는 브라우저 메모리에만 보관됩니다. 새로고침하면 기본 예시가 복구됩니다. 로컬 스토리지, 서버 접수, 메일/SMS 전송 또는 파일 업로드는 없습니다. 파일 선택은 이름만 표시합니다. 운영자 화면은 데모라 별도 인증이 없으며 실제 고객정보를 처리하지 않습니다.

정식 운영 시 고객별 인증·접근 권한, 운영자 권한, 데이터베이스, 접수 알림, 보안 파일 저장, 보고서 승인·발급 이력과 회사 개인정보 정책을 별도로 구현해야 합니다.

회사 기본정보는 사용자가 제공한 2026.08.24 발급 사업자등록증을 기준으로 확인했습니다. 개업일은 2015.10.01이며, 법인 설립일과 구분합니다. 하남 주소는 1동 305·306·307호입니다. 종된사업장 명세에 기재된 대구 사업장도 반영했습니다. 세금계산서 전용 이메일은 일반 상담 이메일과 구분합니다. 사업자등록증 원본은 사이트에 게시하지 않습니다.

공식 로고는 사용자가 제공한 PNG 원본을 변경 없이 사용합니다. 서비스 및 실적 정보 출처: https://smartive.co.kr/ . 회사 통계는 기존 홈페이지 기준으로 표시했으며 현행 수치 확인이 필요합니다. 장비 이미지: https://smartive.co.kr/img/section6_img8.jpg . 공지·대화·의뢰·보고서는 협의용 예시입니다. 본문 글꼴은 Google Fonts를 사용하며 시스템 글꼴로 대체할 수 있습니다.

WebMCP는 지원되는 브라우저에서 현재 데모 의뢰 목록 읽기 및 해당 의뢰 화면 열기 도구를 제공합니다. 테스트용 등록 인터페이스에서 유효·무효 입력과 화면 연결을 검증했으며 네이티브 WebMCP 환경에서는 검증하지 않았습니다.
